# PySend

PySend is a project for transferring files, folders, and other data between nearby devices connected to the same local network. It is being developed as a cross-platform application in Python, with the goal of making local sharing straightforward and accessible.

## Project goals

The project aims to provide a practical way to move data between devices without relying on a remote file-sharing service. It is intended for situations where devices are nearby and can communicate over a local network, whether sharing a single file or a collection of files and folders.

Security and privacy are central goals. The project is being built with care for the data people choose to share and the devices involved. These are development priorities, not a claim that every security feature is already complete.

## How it can be used

The project is intended to support two ways of use:

- As a standalone application for people who want to share data between nearby devices.
- As a reusable module that developers can incorporate into larger projects.

The standalone application is also intended to be distributable as a binary, so users may be able to run it without setting up a Python development environment.

## Development direction

The project is transitioning to Python and is intended to run across multiple platforms. Its functionality and platform support will grow as development continues. The long-term aim is to make local data sharing convenient while keeping the experience focused, approachable, and respectful of user privacy.

This project is open source and free to use. Contributions, feedback, and ideas that help improve its reliability, usability, and privacy are welcome.
